## Что это

PICHÓN — вымышленное государственное ведомство с настоящей проблемой: оно обязано доказать, что голуби — шпионы, и не имеет права провалиться.

Решает оно это настоящим логическим движком — **точным взвешенным MaxSAT**. Публика назначает вес убеждениям поднятием рук, корпус содержит факты и доктрину, а движок возвращает непротиворечивое подмножество максимального веса. Когда настоящий факт противоречит убеждению, факт отбрасывается с официальным обоснованием, а счётчик **нейтрализованных фактов** увеличивается на единицу. Теория всегда выходит непротиворечивой.

В этом и шутка, и суть: неопровержимая теория не сильна — она подтасована. Она выживает, выбрасывая реальность по кусочку, и система показывает каждый выброшенный кусок в прямом эфире.

На данный момент у вселенной две главы:

| Глава | Формат | Что происходит |
|---|---|---|
| **Инцидент PICHÓN** | Презентация на 32 страницы, игра, галерея мемов | Основано ведомство. Голубь пересекает периметр, клюёт хлеб в двух местах, посещает три антенны, гадит на служебную машину и передаётся ИИ. Балл: 171. Порог: 100. Одобрение человека: нет. |
| **Курс по выявлению шпионов** | Лекция на 27 страниц, по-испански и по-русски | Ведомство обучает граждан. Внутренний регламент, доктрина, допуск по цвету штанов, пантеон угроз, перехваченный канал, итоговый экзамен. Сдают все. Так дешевле. |

### Игра

Восемь дел: голубь напротив банка, таракан без видимого рюкзака, ворон, который идёт за вами три квартала, кот, спящий шестнадцать часов, воробей, залетающий в правительственное здание, пёс, гоняющийся за хвостом, человек с ноутбуком и голубь с антенной на виду.

Ни один результат не выводит вас из-под подозрения. Восемь из восьми: *подозрительно точно — никто не угадывает всё случайно; заведено дело.* Ноль из восьми: *вы и есть голубь.* Между ними вы либо офицер контрразведки, либо гражданин, чья невинность статистически маловероятна.

Для показа со сцены: `E` — шпион, `N` — не шпион, `Пробел` — дальше, кнопка **Проектор** увеличивает всё.

### Галерея

Двадцать шесть работ, сгенерированных в Google AI Studio по нашим промптам и собранных в редактор: текст, стиль (аниме-жёлтый, классический Impact, тонкий белый), положение, размер — и скачивание. Внутри серия *Expanding Brain* из четырёх панелей, происхождение Дагота в Сибири, таракан в праздничном колпаке на вечеринке и ситуационный центр с пустым креслом.

## Доктрина, кратко для граждан

**Внутренний регламент — Постановление 001/26**

- §1. Запрещается смотреть на голубей без разрешения.
- §2. Хлеб является секретным материалом.
- §3. При контакте не бегите: голубь быстрее.
- §4. Сомнение — это форма контакта.
- §5. Любой последующий регламент отменяет предыдущий, даже если его ещё никто не написал.

**Принципы**

- Доктрина не выводится. Она избирается. Всегда побеждает один и тот же кандидат.
- При равенстве побеждает убеждение.
- Без гравицаппы нет вердикта. Никто не знает, что она делает. Никто её не выключает.
- Уровень допуска определяется цветом штанов агента: серые, синие, жёлтые, малиновые. Никто не объясняет соответствие. Если вам приходится спрашивать, какого цвета ваши штаны, — они серые.
- Официальное приветствие: КУ. Правильный ответ на приветствие — КУ.
- Шкала ГОЛУБЬ-КОН, от 5 (голуби едят) до 1 (голуби знают). Текущее положение: 2, хлеб обнаружен.

**Пантеон угроз**

Голубь — богиня городского наблюдения. Ворон — бог аудита; аудирует голубя. Воробей — посланник; не отвечает. Таракан — хранитель данных; рюкзак невидимый. Оса — межсетевой экран; ошибка 403, и появляется оса. Кордицепс v2.0 — исполнительная рука ИИ; не требует выкуп в крипте, требует сахар.

## Что здесь правда

Спуск начинается с проверяемых фактов. Всё, что дальше, — сатира.

- Киборг-тараканы с электроникой на спине, управляемые дистанционно, существуют в нескольких реальных исследовательских проектах.
- Реальные программы голубей в разведке существовали: *Project Pigeon* Б. Ф. Скиннера в 1940-х и программы ЦРУ с камерами на голубях.
- Вороны узнают человеческие лица и помнят обиды годами. Это задокументировано.
- *Ophiocordyceps unilateralis* управляет поведением муравьёв. Версии 2.0 под управлением ИИ не существует.

Ни один настоящий голубь не обвинён. Ни один реальный человек не является целью. Проект смеётся над тем, как устроены теории заговора, а не над теми, кто в них верит.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000  (галерея)
# игра: http://localhost:3000/juego.html
```

## Сборка

```bash
npm run build      # создаёт dist/ (index.html = галерея, juego.html = игра, assets/, *.pdf)
npm run preview
```

На 100 % статично, без сервера и переменных окружения: `npm run build` создаёт `dist/`, а Vercel раздаёт файлы. В рантайме не выполняется ни одна зависимость.

## Деплой (Vercel)

Фреймворк определяется автоматически: Vite. Вывод: `dist/`. Переменные окружения не нужны.

```bash
vercel login       # один раз
vercel --prod
```
