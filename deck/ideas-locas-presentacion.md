### 6.5 Print-only watermarks (owner's idea — APPROVED, both directions)

Text/watermark **invisible on screen, visible only when printed**. PDF supports this natively via Optional Content Groups (OCG / "layers") with usage settings `ViewState: OFF, PrintState: ON`.

- Gag copy (print-only, `ViewState: OFF / PrintState: ON`): `ESTA COPIA EN PAPEL HA SIDO REGISTRADA` (This paper copy has been registered) diagonally on every page.
- Reverse gag (screen-only, `ViewState: ON / PrintState: OFF`): `SI USTED IMPRIMIÓ ESTO, LAS PALOMAS YA LO SABEN` (If you printed this, the pigeons already know).
- Implementation: PowerPoint can't do this — post-process the exported PDF with `pikepdf` (OCG + usage application dict) or Acrobat Pro layers. Small script, one pass over the final PDF.
